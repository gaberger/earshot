## New

- **Dictate into any app.** Turn on **Settings → Dictation → Dictate into any app**, click into any
  text field (a web form, an email, a chat), hold **Control + Option + Space** (or a shortcut you choose), speak, and let go.
  Earshot types what you said where your cursor is. It transcribes on your Mac with the same Whisper
  model as your recordings, and the audio is deleted straight away.
  - **Hold or tap.** Switch to **Tap to start, tap to stop** under Settings → Dictation → Mode if holding
    the keys is awkward for long dictations.
  - **Fix words it mishears.** Add corrections such as `ear shot => Earshot` under Settings → Dictation → Corrections.
  - **A fire around the window your words will land in.** While you dictate, a small flame outline burns
    around the window the text will be typed into, so you can see where it is going. It is on by default;
    turn it off in Settings. With Reduce Motion on, it is a plain glowing border.
  - **A small indicator** shows **Listening…** with a live level bar, then **Transcribing…**, and
    **Tidying…** when the option below is on. It never takes focus from your field.
  - **Never typed into the wrong window.** If you switch windows before your words are ready, Earshot does
    not type them anywhere: it leaves them on the clipboard and tells you, so you can press ⌘V where you want them.
  - It never types into password fields, and it stays off while a meeting is being recorded. A dictation stops
    by itself after a minute.
  - It needs **Microphone** and **Accessibility** access; Earshot asks when you turn it on.
- **Tidy up what I say** (optional, off by default). Removes ums and stutters and fixes punctuation
  using Apple's on-device model. It can reword slightly, and if the model is unavailable your words are typed as spoken.
- **Press Return after typing** (optional, off by default). Presses Return once the text is typed, so a chat
  message sends or a form submits. Sending cannot be undone, so you switch this on yourself.
- **Notes.** A separate area for your own voice notes: press **Record a note**, speak, press **Stop**. The text is
  saved in a list grouped by day, with Copy and Delete on each note. Only the text is kept; the audio is deleted at once.
- **Find anything.** One search bar looks across your recordings, notes and settings; press **⌘K** to jump to it.
  The sidebar keeps **Recordings**, **Notes** and **Dictation** one click apart.
- **A clear way back.** Open a recording and a **Recordings / name** link appears at the top left. Click it,
  press **⌘[**, or click **Recordings** in the sidebar to return to the list.
- **Use Earshot from an agent.** `scripts/earshot-mcp` in the project is a small, read-only server that lets an
  agent such as Claude Code list your recordings and read their transcripts and summaries (never the audio). It opens
  no port and uses no network. Whatever agent you connect may send that text to its own provider.
- **Hear replies spoken.** `earshot-speak` speaks a short version of each Claude Code reply with the macOS `say`
  command, for the session you turn it on in. Pressing the dictation hotkey stops the voice so you can talk over it.
- **A new look.** Earshot now has one accent, flame orange, in place of the system blue, with amber for warnings
  and red kept for recording. The app icon is a dark tile with an orange ear and sound waves. The in-app Help
  covers all of the above.

Dictation, Tidy up and Press Return are off until you turn them on, so updating changes nothing you already use.
Tidy up and summaries need Apple Intelligence. Everything runs on your Mac. Apart from the one-time downloads of the
models, the only things that can leave it are what an agent you connect chooses to send to its own provider, and text
you paste yourself from the clipboard. See the security policy, `SECURITY.md`, to report a problem privately.

## Install or update

Download **Earshot-1.1.0.dmg** below, open it, and drag **Earshot** onto **Applications**.
Choose **Replace** if it asks. Your recordings, summaries, models and settings stay as they are.
The app isn't notarized, so macOS may ask again: go to **System Settings → Privacy & Security**
and click **Open Anyway**. After an update, macOS may also forget the Accessibility permission:
if Dictation stops typing, switch Earshot off and on in **Privacy & Security → Accessibility**.

Check the version under **Earshot → About Earshot**. It should read `1.1.0`.
